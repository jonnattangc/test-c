# procesor

Versión más veloz de [`../data_compare`](../data_compare): compara/cruza un archivo de códigos contra logs ubicados en una o más carpetas.

## Compilar

```sh
g++ procesor.cpp -o procesor -Wall -Wextra -Wpedantic -Werror -std=c++17
```

## Ejecutar

```sh
./procesor <archivo> <carpeta1> [carpeta2] [carpeta3]
```
