# operaciones_matrices

Operaciones sobre matrices usando punteros.

## Compilar

Tiene variables sin usar que rompen los flags estrictos del proyecto, por lo que se
compila sin `-Werror`:

```sh
gcc operaciones_matrices.c -o operaciones_matrices -Wall -Wextra -Wpedantic
```

## Ejecutar

```sh
./operaciones_matrices
```
